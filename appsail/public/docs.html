☁️ Infrastructure & Cloud Stack

Persistent Node.js 20 Linux x64 container deployed on Zoho Catalyst AppSail with bundled static FFmpeg and global CORS headers.

  • • Compute: Zoho Catalyst AppSail (PaaS)
  • • Storage: Zoho Stratus Object Storage (HTTP 206 Byte-Range)
  • • Media Engine: Embedded FFmpeg 7.0.2 & FFprobe 7.0.2
  • • Protocol: Fragmented MP4 (fMP4) & Dynamic HLS (m3u8)

GET /api/tracks?key=:stratusKey
Media Stream & Duration Introspection

Executes an in-cloud FFprobe probe on the remote media file. Returns exact duration in seconds and all audio streams with language tags and stream indices. Results are cached in memory.

ParameterTypeDescription
key (query)stringRequired. Zoho Stratus storage key (e.g. Luckyman/Season 01/Luckyman_S01E01__RareToonsIndia_.mkv)
 
// Click "Probe Tracks" to introspect audio streams and duration...
GET /api/stream?key=:key[&audio=:idx][&t=:seconds]
Streaming Proxy & Dynamic Remux

High-performance video streaming endpoint. Proxies HTTP 206 range requests directly from Zoho Stratus, or executes zero-transcode FFmpeg stream copying with AAC audio remuxing when audio track switching or timestamp jumping is requested.

ParameterTypeDescription
key (query)stringRequired. Zoho Stratus object key.
audio (query)integerOptional. Audio stream index (0 = Hindi/default, 1 = Tamil, 2 = Telugu, etc.).
t (query)numberOptional. Timestamp in seconds (e.g. t=90 or t=300). Starts streaming directly from that second with zero delay.
 
// Example: Play Lucky Man Episode 1 in Tamil starting at minute 5:00 (300s):
https://cartoon-server-50046883835.development.catalystappsail.in/api/stream?key=Luckyman%2FSeason%2001%2FLuckyman_S01E01__RareToonsIndia_.mkv&audio=1&t=300
